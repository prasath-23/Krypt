System toasts from Krypt's windowless moments, such as applying an approval and the link receiver. Each is one short sentence with the app's name when it is known.

**Messages**
- **Successes:** "Instagram is open until 14:35"; "Instagram: 1 hour a day until Sep 28"; "Instagram: daily time is set, but today's is used up".
- **Approval errors:**
  - "Couldn't read this reply"
  - "This reply doesn't match a waiting request"
  - "Your request expired before the reply arrived"
  - "This reply couldn't be verified"
  - "Set up Krypt on this phone first"
  - "Turn on automatic date and time, then tap the reply again"

**Rules**
- No full stops at the end of a toast, and never two toasts in a row.
- These use the Android system `Toast`, which draws its own container. This card shows the copy and tone.
