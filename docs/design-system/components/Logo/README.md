The Krypt logo: a keyhole whose round top grows a cat's ears, with a smaller keyhole set into its leg; the guardian and the lock in one silhouette.

**Files** (`assets/Logos`): `krypt-launcher.svg` (108dp adaptive icon, near-white on `#121212`, inside the 66dp safe zone; the same silhouette is the Android 13 monochrome layer), `krypt-mark.svg` (near-black, for light surfaces), `krypt-mark-white.svg` (near-white, for dark surfaces).

**Use**
- One flat silhouette in a single colour (`on-surface`, or near-white on `#121212`), the inner keyhole cut through.
- Lockup: the mark beside "Krypt" in Instrument Serif, the mark about 1.1x the name's cap height; the eyebrow uses the mark at `icon-sm`.
- Clear space: at least half the mark's width on every side. Smallest size: 16dp tall (the inner keyhole may close up below 24dp; that is fine).

**Never** outline it, rotate it, put it in a circle, colour it with a status colour, or add eyes, whiskers or a face.
