# Logos

The Krypt mark is a keyhole whose round top grows a cat's ears, with a smaller keyhole set into its leg. Read fast, it is a keyhole: the one way in. Look again and a cat sits watch over a lock of its own, the old guardian of crypts. The inner keyhole repeats the outer shape: a round top flowing into a stem that flares at the same angle as the leg.

- `krypt-launcher.svg`: the 108dp adaptive-icon canvas, a near-white (`#e8e8e8`) mark on a `#121212` tile, inside Android's 66dp safe zone. For Android 13 themed icons, the same silhouette is the monochrome layer.
- `krypt-mark.svg`: the mark alone in near-black (`#1f1f1f`), for light surfaces.
- `krypt-mark-white.svg`: the mark alone in near-white (`#e8e8e8`), for dark surfaces.
- `krypt-mark-sm.svg`: the optical small size, one path with no inner keyhole and slightly deeper ear notches, in near-black. Use it at 20dp and below: eyebrows, the footer, and the notification small icon (export it as a white-on-transparent vector drawable; Android tints it in the status bar).

**Use:** always one flat silhouette in a single colour, with the inner keyhole cut through. Never outline it, add eyes, whiskers or a face, rotate it, or put it in a circle. Keep clear space of at least half its width on every side. Use the full mark at 24dp and up and `krypt-mark-sm.svg` at 20dp and below. The smallest size is 12dp tall.

There is no wordmark file: set "Krypt" in Instrument Serif beside the mark, or use the eyebrow "KRYPT" with the mark at `icon-sm` size.
